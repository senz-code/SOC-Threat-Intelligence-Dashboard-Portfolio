# SOC-Threat-Intelligence-Dashboard
Beginner Power BI SOC dashboard exploring CISA KEV, FIRST EPSS, CISA advisories, and MITRE ATT&amp;CK with manually refreshed public data.

## Pages

- **CISA KEV:** Exploited vulnerability catalog, vendor chart, and required actions.
- **Advisory overview:** CISA advisory counts, publication dates, source links, and keyword review.

## Sources

- [CISA KEV](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)
- [FIRST EPSS](https://www.first.org/epss/data)
- [CISA advisories](https://www.cisa.gov/cybersecurity-advisories/all.xml)
- [MITRE ATT&CK data and tools](https://attack.mitre.org/resources/attack-data-and-tools/)

## Refresh

Data is manually collected and refreshed in Power BI Desktop.

## Limitations

This project uses public data. It is not matched to an organization's asset inventory,
does not confirm an incident, and does not establish compliance.
